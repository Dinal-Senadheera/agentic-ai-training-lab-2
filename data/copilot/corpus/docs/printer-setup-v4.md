# Receipt printer setup for Aralia POS Cloud

Supported receipt printers are listed in the hardware compatibility matrix.

## Connecting the printer
1. Connect the printer's network cable and the cash drawer cable to the ports shown in
   the back panel figure (img-printer-ports). The figure also shows which socket the
   power supply uses.
2. Give the printer the fixed IP address from the standard store network layout.
3. In Aralia POS Cloud, open Settings > Devices > Printers and select Add printer.
4. Print a test page.

## Paper
Both supported printers take 80 mm thermal paper. Set the paper width to 80 mm in
Settings > Devices > Printers. The default of 58 mm cuts off the right side of receipts.

## Firmware
Keep printer firmware up to date. Epson TM-T82III needs firmware 2.14 or later for
reliable cloud printing.
