# L1 escalation runbook

- Raise a **P1** when an outage affects **3 or more stores**, or any store cannot take
  payments at all.
- For P1, call the L2 on-call engineer on **extension 4410** and open a P1 ticket.
- For everything else, assign the ticket to the L2 queue with the merchant ID, the error
  code and a screenshot.
