# Hardware compatibility matrix

| Device | Type | Classic 3.x | Cloud 4.x |
|---|---|---|---|
| Epson TM-T82III | Receipt printer | Supported | Supported (firmware 2.14+) |
| Xprinter XP-Q80 | Receipt printer | Not supported | Supported from 4.2 |
| Zebra DS2208 | Barcode scanner | Supported | Supported |
| Sunmi T2s | All-in-one terminal | Not supported | Supported |
| Ingenico Move/5000 | Card reader | Supported | Not supported |
| Aralia Pay R2 | Card reader | Not supported | Supported |

Devices not listed are not supported.
