# Release notes: Aralia POS Cloud 4.2 (20 May 2026)

- Added support for the Xprinter XP-Q80 receipt printer. Classic does not support it;
  merchants on Classic must move to Cloud 4.2 or later to use it.
- Offline limit raised from 1,000 to 2,000 transactions.
- Faster product search on large catalogues.
