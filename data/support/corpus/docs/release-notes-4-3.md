# Release notes: Aralia POS Cloud 4.3 (15 September 2026)

- **Loyalty:** points earned on or after 1 October 2026 expire after **18 months**.
  Points earned before 1 October 2026 keep the old 12-month expiry.
- **Refunds:** the manager PIN threshold rises from LKR 25,000 to **LKR 40,000** for all
  merchants. The refunds policy page will be updated separately.
- New error code E-2270 for clock skew.
